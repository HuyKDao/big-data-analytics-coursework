# Big Data Analytics Coursework (Penn CIS 5450)

Write-ups of the technical assignments I completed in **CIS 5450 Big Data Analytics** at the University of Pennsylvania (MSE Data Science, Spring 2026). The course covers the full data science workflow: wrangling, SQL analytics, distributed computing with Spark, classical machine learning and deep learning.

> **About the code:** these assignments are reused each semester, so course policy doesn't allow posting solutions publicly. Each folder explains the problem, my approach, my results and the skills I used. I'm happy to walk through the code in an interview.
